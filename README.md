# NEXUS RS v0.1

Starter project for the NEXUS RS remote sensing coordination and mission-management simulator.

## Included

- Vite + React foundation
- Four playable roles
- Shared mission workspace
- Current Ops and Tomorrow's Plan
- Initial Sync Matrix workspace
- Local incident time only
- Controlled MQ-9, LUH-72, and CAP data
- Generic partner-asset placeholders
- Lt Col Edwards role-aware briefing panel
- Prompt scaffolding
- Responsive desktop and wide-display layout

## Run locally

```powershell
npm install
npm run dev
```

## Build

```powershell
npm run build
```

Use `dev` for Preview and `main` for Production.
