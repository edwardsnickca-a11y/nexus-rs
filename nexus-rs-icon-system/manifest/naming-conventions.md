# NEXUS RS Icon Naming

## SVG files

Use lowercase kebab case:

- `mission.svg`
- `current-ops.svg`
- `tomorrows-plan.svg`
- `intel-oversight.svg`

## SVG sprite IDs

Prefix file slugs with `icon-`:

- `icon-mission`
- `icon-current-ops`
- `icon-intel-oversight`

## React components

Use PascalCase and append `Icon`:

- `MissionIcon`
- `CurrentOpsIcon`
- `IntelligenceOversightIcon`

## Figma components

Use category slash naming:

- `Navigation/Mission`
- `Navigation/Current Ops`
- `Utilities/Search`

## Master Figma properties

Recommended component-set name:

`NEXUS RS/Icon`

Recommended properties:

- Category: Navigation | Utility
- Name: icon name
- State: Default | Hover | Selected | Disabled
- Color: Cyan | White
- Size: 24
